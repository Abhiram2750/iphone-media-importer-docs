iPhone Media Importer - Installer Return Codes

This page documents installer return codes for iPhone Media Importer.

Return Codes

Code Meaning
0 Installation completed successfully.
1 Setup failed to initialize.
2 Installation was cancelled before the actual installation started.
3 A fatal error occurred while preparing the installation.
4 A fatal error occurred during installation.
5 Installation was cancelled during the installation process.
6 The setup process was terminated by the debugger.
7 Setup determined that installation cannot proceed.
8 Setup cannot proceed and a system restart is required.

Support

If you encounter an installer error, please provide the return code and the error message when contacting support.
